# VBS easy creator

A simple Windows batch script that lets you create a .vbs script with a
custom message box no coding required  
uses `cmd.exe` `PowerShell` and `cscript`/`wscript` all built in  
It supports the Russian language

> [!NOTE]
>## How to use
>
>1. Save the script as `generator.bat`
>2. Double-click it (or run from a command prompt)
>3. Follow the prompts
>4. The `.vbs` file will be created in the same folder
